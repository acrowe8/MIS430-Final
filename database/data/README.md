# UA course catalog data

This folder holds the University of Alabama course catalog data used by NextStep UA.

## Files

- **ua_courses_2026-27.csv** — 3,970 undergraduate courses  
  Columns: `subject_code`, `number`, `title`, `description`

- **ua_subjects_2026-27.csv** — 132 subject codes  
  Columns: `code`, `name`

Both files were taken from the official University of Alabama 2026–27 Undergraduate Catalog PDF.

Mary’s resource data will be added to this folder later.
